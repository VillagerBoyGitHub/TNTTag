# TNTTag
![Plugin Logo](logo.png)

An easy-to-use TNTTag minigame plugin I originally made for DarkWix. I decided to publish this plugin because DarkWix is no longer maintained.

I made this plugin because all the other TNTTag plugins are in Spanish and are encrypted, making it impossible to translate the messages and commands.

# Usage
This plugin is compatible with **Genisys API 2.0.0**.

### Commands
- **tnt join** - Allows you to join the minigame.
- **tnt setspawn** - Sets the spawn of the minigame.

### Permissions
- **tnt.setspawn** - Allows you to use /tnt setspawn.

# Requirements
- [PocketUtils](https://github.com/VillagerBoyGitHub/PocketUtils)
